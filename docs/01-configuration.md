# Глава 1. Первоначальная настройка (Configuration)

Перед началом создания коммитов в Git необходимо указать имя автора и адрес электронной почты. Эти метаданные сохраняются в каждом коммите и связывают сделанные изменения с вашей личностью.

---

## 1. Уровни конфигурации Git

Конфигурация Git делится на три уровня, определяющих область видимости настроек:

| Уровень | Флаг | Где хранится | Описание |
| :--- | :--- | :--- | :--- |
| **System** | `--system` | `/etc/gitconfig` | Действует для всех пользователей операционной системы |
| **Global** | `--global` | `~/.gitconfig` | Действует для всех репозиториев текущего пользователя |
| **Local** | `--local` (по умолчанию) | `.git/config` | Действует **только** для текущего репозитория |

Приоритет настроек идёт от частного к общему: **`local` переопределяет `global`, а `global` переопределяет `system`**.

---

## 2. Разбор антипаттерна: почему `git config --global` — плохой паттерн?

Многие вводные инструкции предлагают сразу выполнить:
```bash
git config --global user.name "Ваше Имя"
git config --global user.email "your.email@example.com"
```

> [!WARNING]
> **Минусы использования глобальной настройки:**
> 1. **Смешение контекстов (работа / учёба / pet-проекты):**
>    Современный разработчик часто совмещает разные активности на одном компьютере (учебный аккаунт в ВШЭ, корпоративный GitLab на работе, личный профиль на GitHub). Задав глобальную почту, вы неизбежно начнёте отправлять коммиты с корпоративной почты в учебные репозитории или наоборот.
> 2. **Утечка приватной информации:**
>    Использование глобального email может случайно раскрыть вашу личную или внутреннюю корпоративную почту в открытом open-source репозитории.
> 3. **Проблемы с кириллицей:**
>    Имя пользователя (`user.name`) не следует указывать на кириллице. В некоторых консолях, CI/CD системах или git-хуках кириллические символы могут отображаться некорректно или приводить к сбоям кодировки. Используйте латинскую транслитерацию (например, `"Pavel Akhtyamov"`).

---

## 3. Рекомендуемый подход к настройке

Лучшая практика — настраивать имя и почту **локально** под каждый отдельный репозиторий:

```bash
# 1. Перейдите в каталог проекта
cd /path/to/my-repo

# 2. Настройте имя и почту для этого репозитория
git config user.name "Ivan Ivanov"
git config user.email "iivanov@edu.hse.ru"
```

### Просмотр текущей конфигурации
Чтобы убедиться, какие именно значения действуют в текущем проекте и откуда они берутся:

```bash
# Показать все настройки и путь к файлу конфигурации, где они заданы
git config --list --show-origin
```
