# Глава 4. История коммитов (History & Log)

В этой главе рассматриваются способы исследования истории проекта, поиска изменений и визуализации графа коммитов в терминале.

---

## 1. Базовый просмотр истории: `git log`

Команда `git log` отображает список коммитов в обратном хронологическом порядке:

```bash
git log
```

Для каждого коммита выводится:
* Полный 40-символьный SHA-1 / SHA-256 хэш коммита;
* Автор (имя и email);
* Дата и время создания;
* Полное сообщение коммита.

Для постраничного выхода из режима просмотра нажмите клавишу `q`.

---

## 2. Компактный вывод: `git log --oneline`

Когда проект разрастается, стандартный вывод становится слишком громоздким. Флаг `--oneline` сокращает каждый коммит до одной строки:

```bash
git log --oneline
```

Формат: `короткий_хэш краткое_сообщение`.

---

## 3. Графическое дерево коммитов: `git log --graph`

Самый наглядный и полезный вариант команды — отображение истории в виде псевдографического дерева со всеми ветками:

```bash
git log --graph --oneline --all
```

* `--graph` — рисует ASCII-дерево слияний и ветвлений;
* `--oneline` — держит вывод компактным;
* `--all` — показывает историю **всех** веток, а не только текущей.

Пример вывода:
```text
*   7bcda8e (HEAD -> main) Fixed merge conflict
|\  
| * ea43fc1 Added preparing
| * 09cf1ae Added missing cached
* | a7e8fed Added acknowledgments
|/  
* c91b161 Added documentation to project
* f893556 First commit to my repository
```

---

## 4. Детализация конкретного коммита: `git show`

Чтобы посмотреть, какие именно строки были добавлены или удалены в рамках конкретного коммита:

```bash
git show <хэш_коммита>

# Пример:
git show 7bcda8e
```

---

## 5. Полезные фильтры истории

```bash
# Ограничить вывод последними N коммитами
git log -n 5 --oneline

# Поиск коммитов по автору
git log --author="Akhtyamov"

# Поиск по тексту в сообщении коммита
git log --grep="conflict"

# История изменений конкретного файла
git log -p path/to/file.py
```
